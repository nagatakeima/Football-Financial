# 07_3. チーム戦術＆局面別意思決定アルゴリズム (Team Tactics & Decision Protocol)

## 1. 設計思想：チーム戦術とは「バフ」ではなく「意思決定のプロトコル」である

チーム戦術（ポゼッション、ハイプレス、カウンター、リトリート等）は、選手の能力値（ステータス）を上下させる魔法のバフではない。
AIが毎Tick（フレーム）行うUtility AIの評価計算において、**「どの程度のリスクを許容するか」「どのタイミングでテンポを変えるか（急襲のスイッチ）」「味方とどう連動するか」を規定する意思決定プロトコル（行動指針の重み付け）**である。

そのため、選択したフォーメーション（初期配置と可変構造）とこの戦術プロトコルの間には、**「構造的な有利・不利（相性）」**が必然的に発生する。

---

## 2. 戦術を実現する4つのコア・メカニズム（エンジン共通処理）

各戦術の個性をピッチ上で再現するため、エンジンは以下の4つの特殊な評価アルゴリズム（意思決定のトリガー）を持つ。

### 2.1 リスク許容度閾値 (Action Risk Threshold)
パスやドリブルを選択する際、「成功確率が何%以上なら実行に移すか」のボーダーライン。
*   **安全重視（例：ビルドアップ時のポゼッション）：** 閾値が高い（例：75%以上）。前方のパスコースの成功率が低ければ、無理に通さず横パスやバックパス（`Pass_Short`）、キープ（`Keep`）のスコアが高くなり作り直す。
*   **試行重視（例：ゲーゲンプレス時の裏狙い）：** 閾値が低い（例：40%以上）。インターセプトされるリスクが高くても、敵DF裏にスペースがあれば積極的に `Pass_Through` を試行するようスコアが補正される。

### 2.2 ポジション交換（ローテーション / Slot Swap）
攻撃時、同じ場所にとどまらず選手同士が流動的に場所を入れ替え、相手のマーク（特にマンツーマン守備）に「受け渡しの混乱」を生じさせるロジック。
*   近接するレーン・階層にいる味方（特にケミストリーリンクが繋がっているペア）の間で、`Msg_RequestSwap` のメッセージを送受信する。
*   成立した場合、2人の目標スロット（例：`[R-Half]` のCMと `[R-Out]` のW）を一時的に交換し、互いに逆方向へクロスムーブを行う行動スコアが最大化する。

### 2.3 急襲スイッチ（Tempo Switch / Penetration Trigger）
ゆっくりボールを回している状態から、一瞬でゴールへ直結する攻撃へギアを上げるトリガー判定。
*   エンジンは常時「相手の守備ラインの乱れ」を空間認識（FOV）を通して監視する。
*   **トリガー条件：**
    1.  ポジション交換やサイドチェンジにより、相手DF-MF間の「ライン間（ポケットやバイタル）」に味方が前向きでフリーになった瞬間。
    2.  相手DFラインの横の選手間距離（ゲート）が一定以上（例：15m以上）開いた瞬間。
*   上記を検知した瞬間、チーム全体のモードが `Build_Up` から `Penetration（急襲）` に切り替わり、一斉にスルーパスと裏抜けの評価スコアが爆発的に上昇する。

### 2.4 予測トランジション（Pre-emptive Transition）
ボールが実際に奪われる（または奪う）前の「パスが出た瞬間（ボール移動中）」から、次の局面の行動をフライング開始するロジック。
*   **攻撃→守備の予測（ロスト前提の囲い込み）：** 味方がリスクの高い縦パスやスルーパスを出した瞬間、周囲の味方AIは「そのパスが相手DFにカットされる確率」を計算し、着弾地点の周囲へあらかじめスプリント（予測ゲーゲンプレス）を開始するスコアを高める。
*   **守備→攻撃の予測（インターセプト連動）：** 味方DFがパスカットやクリアのモーションに入る瞬間、前線の選手は守備ブロックから離脱し、一足先に相手背後のスペースへ走り出す `Run_into_Space` スコアを高める。

## 3. 各チーム戦術の局面別詳細アルゴリズム

本作の基本となる4大戦術志向について、4局面（+切り替え）およびセットプレーにおける具体的なAIの振る舞い（スコアバイアス）を定義する。

### 【戦術①】ポゼッション (Possession / Positional Play)
*～ボールと空間を支配し、絶え間ない位置交換で相手を動かして急所を刺す～*

*   **A. ボール保持時 (Attack):**
    *   **ビルドアップ＆前進:** テンポは低速〜中速（リスク許容度閾値が極めて高い）。確実なショートパスとサポートに極大のプラス補正。GKを11人目のフィールドプレイヤーとして扱い、ロングクリアのスコアは極端に下がる。
    *   **ポジション交換と崩し:** 敵陣に押し込んだ状態では、隣接スロットの味方同士で **「ポジション交換（Slot Swap）」** の発生確率が最大化する。パスとローテーションを繰り返す。
    *   **【急襲スイッチ】:** 相手のマーク受け渡しミスや、ハーフスペースへの縦パスが入った瞬間、一気にワンタッチパスと裏抜けを連続発動する。
*   **B. ネガティブ・トランジション (喪失直後):**
    *   ボールロスト地点の近くにいる選手2〜3人が即座に寄せ、パスの出どころを塞ぐ（即時奪回または戦術的ファウル・ディレイ）スコアが上昇する。
*   **C. ボール非保持時 (Defense):**
    *   **相手ビルドアップ時（誘導トラップ）:** 1stディフェンダーが中央のコースをカバーシャドウしながらアプローチし、相手を「タッチライン際」へ追い込む。誘導エリアにパスが出た瞬間、周囲が一斉にインターセプトを狙う。
*   **D. ポジティブ・トランジション (奪取直後):**
    *   無理な縦パスは蹴らず、一度フリーの味方へ確実なパスを繋いでボールを落ち着かせ、即座に攻撃陣形（例：`3-2-5`）へ広がる行動を優先する。
*   **E. セットプレー傾向:**
    *   **攻撃時:** CKやFKでは「ショートリスタート」の選択率が極めて高い。
    *   **守備時:** ペナルティエリアのラインを高く保ち、クリア後は素早くラインを押し上げる。

### 【戦術②】ハイプレス / ゲーゲンプレス (Gegenpressing / Storming)
*～縦への執拗なアタックと、失った瞬間を最大のチャンスに変える狂気の狩り～*

*   **A. ボール保持時 (Attack):**
    *   **ビルドアップ＆前進:** テンポは高速・縦志向。横パスやバックパスの評価スコアが減衰し、多少リスクがあっても前線へ縦パスを差し込む。
    *   **フィニッシュワーク:** 前線は裏抜け（`Run_into_Space`）を絶え間なく繰り返し、ボール保持者はリスク許容度閾値を下げて積極的にスルーパスを狙う。
*   **B. ネガティブ・トランジション (喪失直後) ※最重要:**
    *   **5秒ルール:** ボールを失った瞬間、基本陣形に戻る思考を完全にロックする。ボール周囲の全味方選手の `Press_Ball` スコアが極大化し、複数人での囲い込みを5〜6秒間フルスプリントで実行する。
*   **C. ボール非保持時 (Defense):**
    *   最終ラインをハーフウェイライン付近まで高く設定。相手が自陣でボールを持った瞬間、CFのプレスをトリガーとして中盤・SBまでが連鎖的に縦スライドし、1秒も時間を与えない急襲プレスをかける。
*   **D. ポジティブ・トランジション (奪取直後):**
    *   **超速ショートカウンター:** パスを落ち着かせる選択肢を排除。3手以内でフィニッシュまで持ち込むため、前線が一斉にゴールへスプリントする。
*   **E. セットプレー傾向:**
    *   **攻撃時:** 速い弾道でゴール前へ蹴り込み、こぼれ球（セカンドボール）を即時回収する。
    *   **守備時（カウンター配置）:** スピードの高い前線選手をハーフウェイライン付近に残し、クリア直後の数的優位ロングカウンターを狙う。

### 【戦術③】カウンター / ダイレクト (Direct Counter-Attack)
*～自陣に誘い込んで牙を研ぎ、奪った瞬間に広大な背後を刺し貫く一撃必殺～*

*   **A. ボール保持時 (Attack):**
    *   テンポは極めて速い。自陣での細かいパス回しを避け、早い段階で前線のターゲットマンへのロングパスやサイドへの展開を選ぶ。手数をかけず早めに攻撃を完結させる。
*   **B. ネガティブ・トランジション (喪失直後):**
    *   即時奪回は行わない。最前線が `Delay` を行っている間に、残りの全選手が自陣の守備ブロック座標へ全速力で帰陣（リトリート）するスコアが最大化する。
*   **C. ボール非保持時 (Defense):**
    *   **ミドル〜ローブロック:** ハーフウェイライン〜自陣サードの手前に強固なブロックを敷く。相手CBにあえてボールを持たせて前進させ、中盤のフィルターゾーンに縦パスが入った瞬間をトリガーとして挟み込む。
*   **D. ポジティブ・トランジション (奪取直後) ※最重要:**
    *   **ロングカウンター:** 自陣で奪った瞬間、前線は相手DFラインの背後スペースへ向けて迷わずロングスプリントを開始する。ボール保持者は最優先でそのスペースへ長距離のパスを供給する。
*   **E. セットプレー傾向:**
    *   **攻撃時:** ロングスローやGKからの超長距離パントキックを好む。
    *   **守備時:** クリアボールの落下予測地点に中継役とスピードスターを配置し、決定的なパスに繋げる。

### 【戦術④】リトリート / 堅守 (Low Block / Park the Bus)
*～空間と時間を完全に凍結させ、絶対的な城塞を築いて1点を守り抜く～*

*   **A. ボール保持時 (Attack):**
    *   **徹底したリスク排除:** 自陣でのボールロストを最大の禁忌とする。プレッシャーを感じればセーフティクリアを選ぶ。攻撃参加人数を最小限（2〜3人）に制限し、常に後方に守備要員を残す。
*   **B. ネガティブ・トランジション (喪失直後):**
    *   後方に人数が残っているため陣形が崩れない。前線の選手も即座に下がり、多層ブロック（`5-4-1` など）を再形成する。
*   **C. ボール非保持時 (Defense):**
    *   **ペナルティエリア前の完全封鎖:** 最終ラインを深く固定し、DF-MFライン間を極限まで圧縮する。無闇に飛び込まず、常に `Delay` とシュートブロックコースの確保を優先する。
*   **D. ポジティブ・トランジション (奪取直後):**
    *   前線に孤立しているCFへロングボールを蹴り込み、CFが `Keep` を行うことで、チーム全体のスタミナ回復と陣形押し上げの時間を稼ぐ。
*   **E. セットプレー傾向:**
    *   **攻撃時:** 長身CBを前線に上げ、貴重な得点源として時間をたっぷり使う。
    *   **守備時:** 全員を自陣PA周辺に配置し、カウンター要員すら残さず空間を物理的に埋め尽くす。

## 4. フォーメーション × チーム戦術の「構造的有利不利」マトリクス

チーム戦術は「目標とする振る舞い（スコアバイアス）」を強制するため、選択したフォーメーションの初期配置（アンカー）や選手のロールと噛み合わない場合、ピッチ上で**構造的摩擦（ペナルティではなく物理的な不都合）**が発生する。

| チーム戦術 | 相性が良い構造（有利） | 構造的摩擦が起きやすい例（不利・要ロール補完） |
| :--- | :--- | :--- |
| **ポゼッション** | **`4-3-3` / `3-4-2-1`**<br>初期状態で三角形が多く、5レーン・3階層に人が分散しているため、少ない移動距離でパスコースとポジション交換が成立する。 | **`4-4-2 (フラット)`**<br>4人が横一線に並ぶため斜めのパスコースが作りにくく、ハーフスペースに人がいないためビルドアップが外回りで詰まりやすい（※偽SBや偽9番のロール補完で解決可能）。 |
| **ゲーゲンプレス** | **`4-3-3` / `4-2-3-1` / `4-4-2 (ダイヤ)`**<br>前線・中盤の高い位置に人数が多く、縦の連動スライドとロスト直後の囲い込み網を即座に形成できる。 | **`5-3-2` / `5-4-1`**<br>最終ラインに5人が拘束されるため前線のプレス枚数が足りず、相手のビルドアップに対して後手に回りやすい（※WBを極端に押し上げるロール設定が必須）。 |
| **カウンター** | **`4-4-2` / `3-5-2` / `4-2-3-1`**<br>自陣を4-4や5-3のブロックで固めやすく、かつ前線に2人以上残るため、奪った瞬間に少ない手数で完結できる。 | **`4-3-3 (アンカー1枚＋高位置SB)`**<br>SBを上げすぎるとカウンター前に自陣のスペースを突かれやすく、引くと1トップが孤立してロングボールの収まりどころがなくなる。 |
| **リトリート** | **`5-4-1` / `4-5-1` / `5-3-2`**<br>最初から5レーンを物理的に埋める守備ラインが存在し、スライドの遅れによるギャップが生まれない。 | **`3-4-3` / `4-3-3 (攻撃的W)`**<br>ウイングが守備に降りないロールの場合、自陣に引いた際にサイド（SB前のスペース）が広大に空き、クロスを浴び続ける構造的欠陥が生じる。 |
