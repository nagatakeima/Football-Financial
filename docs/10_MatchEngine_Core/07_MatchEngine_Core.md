# 07. 試合エンジン・コア (Match Engine Core)

本ドキュメントは、『サバイバル・フットボール・ローグライト（仮）』の試合シミュレーションにおける、全選手（AIエージェント）に共通する「物理空間の認識」と「思考の根幹ルール」を定義する。
本作のAIは、全体を強制的に統制する上位AIを持たず、選手個人が Utility AI を用いて自己判断し、味方と連携する**ボトムアップ型のアーキテクチャ**を採用する。
※物理演算や描画は、Phaser 3 の枠組み（Z軸を独自拡張）で処理する。

---

## 1. 空間認識と物理法則

### 1.1. 座標系とPitch Matrix (5レーンと3サード)
本作のAIは、単純なX,Y座標に加えて、ピッチを分割した「Pitch Matrix」により空間を概念的に認識する。これが選手の基本ポジションや戦術的判断の基礎となる。

*   **X軸 (横幅) - 5レーン:**
    1. 左アウトサイドレーン (Left Outside)
    2. 左ハーフスペース (Left Half-space)
    3. センターレーン (Center)
    4. 右ハーフスペース (Right Half-space)
    5. 右アウトサイドレーン (Right Outside)
*   **Y軸 (縦幅) - 3サード:**
    1. ディフェンシブ・サード (Defensive Third / 自陣)
    2. ミドル・サード (Middle Third / 中盤)
    3. アタッキング・サード (Attacking Third / 敵陣)
*   **特殊エリア:**
    *   ペナルティエリア (Penalty Area): GKの手が使える範囲。攻守における「リスクとリターン」の評価スコアが跳ね上がる。
    *   ハーフウェイライン (Halfway Line): オフサイド判定の絶対的境界線。

*   **Z軸（高さ）とインターセプト判定:** ボール(X,Y)が選手の当たり判定半径内にあり、かつZ座標が「選手のジャンプ最大到達点」以下である場合のみ干渉可能。GKのみペナルティエリア内ではZ軸方向の干渉限界（手の判定）が大きく拡張される。

### 1.2. ボールの物理挙動（バウンド、回転、環境）
*   **重力とバウンド:** 地面(Z=0)接地時、反発係数と摩擦係数によりバウンド・減速する。天候（雨など）によって係数が変動。
*   **回転 (Spin):** キック時のスピンベクトルにより、飛行軌道が曲がる（カーブ）、または接地時に急減速する（バックスピン）。
*   **パスの受けやすさ（球質）:** パスの「強さ」「回転」「高さ」が、後述のファーストタッチ判定の難易度に直結する。

### 1.3. 認識空間（ヒートマップ）とオフサイドライン
*   **プレッシャーマップ / スペースマップ:** 敵の圧力、および安全地帯のヒートマップ。Pitch Matrixの特定レーン/サードと組み合わされ、「右ハーフスペースが空いている」等の高度な認識に繋がる。
*   **オフサイドラインの認識:** 守備側AIが構築する動的なY座標ベースの壁（ハーフウェイラインより自陣側のみ有効）。攻撃側AIはこれを「仮想的な壁」として認識し、飛び出すタイミング（スコア計算）の基準とする。

### 1.4. 視野角 (FOV) と空間把握（首振り）
*   **FOVと首振り (Scanning):** 選手の基本視野角（前方）に対し、頻繁に首を振ることで瞬間的に視野を回転させる。
*   **空間記憶 (Mentalの作用):** `Mental`ステータスが高いほど首振り頻度が高く、視界に捉えた敵味方の位置を**脳内マップに長く保持**できる。これにより、後ろを向いていても正確なパスが可能。

### 1.5. 基礎ステータスと移動・物理
*   **速度・加速度:** `スピード` に依存。
*   **減速度 (Agility):** `フィジカル` と `スピード` の組み合わせ。急停止や切り返しにより、敵の慣性を突く。
*   **ジャンプ:** `フィジカル`（および身長）に依存。

### 1.6. ファーストタッチ (ボールコントロール)
ボールを受ける際、以下の要素で「トラップの乱数（足元からの距離）」を計算する。
*   **入力:** ボールの球質（速度、回転、バウンド状態） ＋ 敵のプレッシャー（マップ値）。
*   **処理:** 該当ステータスと `メンタル` を基に成功率を算出。失敗（ノイズ大）するとボールが足元から離れ、ルーズボール扱いとなる。
*   **意図的なトラップ:** パスやシュートといった「次のアクション」のスコアが既に高い場合、その方向へ意図的にボールを置く（方向付けられたファーストタッチ）。

## 2. サッカーの局面 (The Phases of Play)

### 2.1. インプレーの4局面 (Main Phases)
1.  **Attack (保持):** Build Up (自陣), Progression (中盤), Final Third (敵陣深く)
2.  **Defense (非保持):** High Press (敵陣), Mid Block (中盤), Low Block (自陣深く/撤退)
3.  **Positive Transition:** 奪った瞬間。カウンターのスコアが急増。
4.  **Negative Transition:** 奪われた瞬間。即時奪回か撤退かの判断。

### 2.2. 第5の局面: Set Piece (セットプレー)
キックオフ、CK、FK、スローイン等のリスタート時。自律AIは一時中断され、専用の配置と特殊ステートが適用される。

## 3. AIの基本ステートマシン (State Machine)

### 3.1. ボール保持時
*   Keep (キープ), Dribble (運ぶ/抜く), Pass (ショート/スルー/ロング), Shoot, Clear.

### 3.2. ボール非保持時・味方保持
*   Support (サポート), Run into Space (スペース/裏へのラン), Hold Position (バランス維持).

### 3.3. ボール非保持時・敵保持
*   Press (プレス), Mark (マーク), Cover (カバー), Delay (ディレイ), Retreat (リトリート).

## 4. Utility AI 評価関数 (Evaluation Function)

### 4.1. 基本式とTick
`Score(A_i) = (BaseWeight * ContextModifier * TacticalDirective) + MessageBonus + Noise`
*   `Mental` が高いほど、評価を回す思考サイクル（Tick）が短く、反応が速い。

### 4.2. チーム戦術（Tactical Directives）による指針
監督が設定した「チーム戦術（例：ポゼッション、カウンター）」は、単なるステータスバフではなく、AIの `TacticalDirective` 乗数として働き、チーム全体の**「振る舞いの指針」**となる。
これにより、フォーメーションの配置と戦術の間に構造的な相性（有利不利）が発生する。

*   **ポゼッション:** Pitch Matrixの「中央（センター/ハーフスペース）」を重視し、選手間の距離を縮める。ショートパスと即時奪回（ゲーゲンプレス）のスコアが激増する。
*   **カウンター:** 奪った瞬間、敵陣深く（アタッキングサード）へのスルーパスや裏へのランスコアが最大化。非保持時は自陣に撤退（リトリート）し、中央を固める。
*   **サイド攻撃:** 保持時、最優先で「アウトサイドレーン」に展開する。クロスボールと、それに合わせるためのPA内への飛び込みスコアが上がる。
*   **ハイプレス:** 非保持時、アタッキングサードからでも激しくプレッシャーをかける。高い位置で奪えば「ショートカウンター」ボーナスが入るが、スタミナ消費が劇的に激しくなる。

### 4.3. スタミナ消費と回復ロジック
*   **消費 (Drain):** スプリント（ダッシュ）、急激な方向転換、ジャンプ、ボディコンタクトの発生時に大きく消費する。基本のジョグ移動では微量消費。
*   **回復 (Recovery):**
    *   歩行・停止時（非関与時）に徐々に微量回復。
    *   セットプレー等でプレーが止まった（Dead Ball）際にボーナス回復。
    *   ハーフタイムで一定割合（例：最大値の40%など）回復。
*   **疲労のデバフ:** スタミナ低下時、速度や跳躍力の低下に加え、**判断力の低下（IQ Drop）**が発生。視野が狭まり（首振り減少）、評価のノイズが増幅する。

## 5. 連動とメッセージング基盤 (Coaching)

*   **メッセージ:** 「俺がプレスに行く」「裏へ走る」といった情報を対象空間・味方へ発信。
*   **ケミストリーの影響:** リンクが繋がっている（戦術志向が一致）味方同士は、メッセージの処理速度・スコア加算（MessageBonus）が高く、素早い連携が可能。
