# 00. 選手役割（ロール）リスト (Player Roles List)

本作の選手は、獲得時に「ポジション」と「役割（ロール）」がセットで決定される。
役割は、選手の能力傾向だけでなく、Pitch Matrix（5レーン×3サード）上での基本立ち位置や、思考のバイアス（特定アクションのスコア加算）として機能する。

以下に全9ポジションに対する役割リストとその特徴を定義する。

---

## 1. GK (ゴールキーパー) - 2種

*   **クラシック (Classic):**
    *   **特徴:** ペナルティエリア内に留まり、シュートストップと確実なキャッチングを最優先する伝統的GK。
    *   **行動バイアス:** PA外に出る（飛び出し）スコアが低い。セービング技術と反応速度のステータスが高く生成されやすい。
*   **スイーパー (Sweeper):**
    *   **特徴:** ペナルティエリア外（自陣深く）まで積極的に飛び出し、裏へのスルーパスのケアやビルドアップに参加するGK。
    *   **行動バイアス:** ディフェンシブ・サードにおける味方DFライン背後のスペースへのカバーランスコアが高い。足元の技術とスピードが高く生成されやすい。

## 2. CB (センターバック) - 3種

*   **ストッパー (Stopper):**
    *   **特徴:** 敵CFに対してタイトにマークし、積極的に前へ出てボールを奪いに行く武闘派CB。
    *   **行動バイアス:** 「Press / Tackle」のスコア加算が大きい。ディフェンシブ・サードにおいて、相手との距離を詰める行動を好む。
*   **カバーリング (Covering):**
    *   **特徴:** ラインの背後や味方のカバーを優先し、ディレイをかけながらボールを回収する頭脳派CB。
    *   **行動バイアス:** 「Delay / Retreat」および味方の背後への「Hold Position」スコアが高い。
*   **ボールプレイング (Ball-Playing):**
    *   **特徴:** 奪った後のパス出しや、自らボールを運んでビルドアップに参加することを得意とするCB。
    *   **行動バイアス:** ボール保持時、ミドル・サードへ向かって「Dribble (運ぶ)」や前線への「Pass」のスコアが加算される。パス精度とMentalが高く生成されやすい。

## 3. SB (サイドバック) - 4種

*   **守備的SB (Defensive):**
    *   **特徴:** 攻撃時も自陣サードに残り、擬似的な3バックを形成してリスク管理を徹底する。CBへのサブ適性を持ちやすい。
    *   **行動バイアス:** 保持時でもディフェンシブ・サードに留まるスコアが高く、オーバーラップを行わない。
*   **攻撃的SB / オーバーラップ (Attacking):**
    *   **特徴:** アウトサイドレーンを上下動し、Wの外側を回ってクロスを上げる古典的スタイル。
    *   **行動バイアス:** 味方Wがボールを持った際、アウトサイドレーンでの「Run into Space (オーバーラップ)」スコアが激増。クロス精度とスタミナが高い。
*   **インバーテッド / 偽SB (Inverted):**
    *   **特徴:** 攻撃時に中央（ハーフスペースやセンターレーン）へ絞り、MFのようにビルドアップやネガティブトランジションの防波堤となる。CDM/CMへのサブ適性を持ちやすい。
    *   **行動バイアス:** 保持時、ミドル・サードのハーフスペースまたはセンターレーンへの移動スコアが高い。
*   **ウイングバック (Wing-Back):**
    *   **特徴:** SBより高い位置を基本陣形とし、一人でサイド全体を制圧する。3バック/5バック戦術で輝く。WB/SHポジションとしての役割と重複・互換性を持つ。
    *   **行動バイアス:** 常時ミドル・サードのアウトサイドレーンを基準位置とし、上下動のスコアが全体的に高い。

## 4. CDM (守備的ミッドフィルダー) - 3種

*   **アンカー (Anchor):**
    *   **特徴:** 最終ラインの前にどっしり構え、バイタルエリア（中央）を埋める門番。
    *   **行動バイアス:** ミドル・サード下部〜ディフェンシブ・サードのセンターレーンから動かない（Hold Positionスコアが高い）。
*   **デストロイヤー (Destroyer):**
    *   **特徴:** 中盤の広範囲を動き回り、ボールホルダーに対して強烈なプレスをかけてボールを刈り取る狂犬。
    *   **行動バイアス:** ミドル・サード全域において「Press / Tackle」スコアが急増。スタミナとフィジカルが高い。
*   **レジスタ / ディープライイング (Deep-Lying Playmaker):**
    *   **特徴:** 低い位置から長短のパスでゲームメイクを行う司令塔。
    *   **行動バイアス:** ディフェンシブ・サード上部〜ミドル・サード下部でボールを要求するスコアが高い。Mentalとパス精度が極めて高い。

## 5. CM (セントラルミッドフィルダー) - 3種

*   **Box-to-Box (B2B):**
    *   **特徴:** 自陣PAから敵陣PAまで絶え間なく上下動し、攻守両面に顔を出す万能型。
    *   **行動バイアス:** 縦への「Run into Space」と「Retreat」スコアが常に高く、広範囲のサードを行き来する。無尽蔵のスタミナが必須。
*   **アドバンスド・プレイメーカー (Advanced Playmaker):**
    *   **特徴:** 敵陣サードのハーフスペースなどでボールを引き出し、決定的なスルーパスを狙う。CAMへのサブ適性を持ちやすい。
    *   **行動バイアス:** アタッキング・サードのハーフスペースへのポジショニングスコアと、前線への「Pass (スルーパス)」スコアが高い。
*   **ボールウィニング (Ball-Winning):**
    *   **特徴:** CMの位置から前線へのプレスを牽引し、高い位置でのボール奪取を狙う。
    *   **行動バイアス:** ミドル〜アタッキング・サードでの「Press」スコアが高い。デストロイヤーの前傾姿勢版。

## 6. CAM (攻撃的ミッドフィルダー) - 3種

*   **シャドウストライカー (Shadow Striker):**
    *   **特徴:** CFの後方からPAへ侵入し、自ら得点を狙うことに特化したアタッカー。CFへのサブ適性を持ちやすい。
    *   **行動バイアス:** CFが空けたスペース（アタッキング・サードのセンターレーン/PA内）への「Run into Space」および「Shoot」スコアが高い。
*   **エンガンチェ / クラシックNo.10 (Enganche):**
    *   **特徴:** あまり動き回らず、バイタルエリア（中央）でボールを待ち受け、テクニックとパスでチャンスを演出する王様。
    *   **行動バイアス:** アタッキング・サードのセンターレーンに留まる「Hold Position」スコアが高く、パススコアに大きなボーナスがかかる。守備参加（Press）スコアは極端に低い。
*   **ダイナモ (Dynamo):**
    *   **特徴:** 豊富な運動量で前線からのハイプレスを牽引し、敵DFを追い回す守備的トップ下。
    *   **行動バイアス:** アタッキング・サード全域での「Press」スコアが最大化される。スタミナが高い。

## 7. WB / SH (ウイングバック / サイドハーフ) - 3種

*   **クロッサー (Crosser):**
    *   **特徴:** 敵陣深くのアウトサイドレーンまで抉り、正確なクロスを供給することに特化した職人。
    *   **行動バイアス:** アタッキング・サードのアウトサイドレーンへの進行と「Cross」のスコアが極めて高い。
*   **ワイドプレイメーカー (Wide Playmaker):**
    *   **特徴:** サイドからハーフスペースへ絞り、ゲームメイクを行う。CM/CAMへのサブ適性を持ちやすい。
    *   **行動バイアス:** 保持時、ミドル〜アタッキング・サードにおいてアウトサイドからハーフスペースへの斜めの移動スコアが高い。
*   **ハードワーカー (Hard-Worker):**
    *   **特徴:** サイドの攻守において泥臭く上下動を繰り返し、SBの守備負担を大きく減らす汗かき役。
    *   **行動バイアス:** 非保持時の「Retreat」および自陣深くでの守備アクションスコアが高い。

## 8. W (ウイング) - 3種

*   **ウインガー (Classic Winger):**
    *   **特徴:** アウトサイドレーンに張り、ドリブルで縦への突破とクロスを狙う純粋なサイドアタッカー。
    *   **行動バイアス:** アタッキング・サードのアウトサイドレーンでの「Dribble」スコアが高い。スピードと敏捷性が高い。
*   **インサイドフォワード (Inside Forward):**
    *   **特徴:** 逆足（右サイドなら左利き）を活かし、ハーフスペースから中央へカットインして直接シュートを狙う。CFへのサブ適性を持ちやすい。
    *   **行動バイアス:** アタッキング・サードにおいて、アウトサイドからハーフスペース/センターへ向かっての「Dribble」および「Shoot」スコアが高い。
*   **ターゲットマン・ワイド (Wide Target Man):**
    *   **特徴:** サイドに配置される長身選手。SBと競り合うことで空中戦の優位を作り、起点となる。
    *   **行動バイアス:** 浮き球のパスを受ける際のポジション取りスコアが高く、フィジカルとジャンプ力が高い。

## 9. CF (センターフォワード) - 4種

*   **ポーチャー / 点取り屋 (Poacher):**
    *   **特徴:** PA内での駆け引きとワンタッチシュートに特化。ラインの裏抜け（飛び出し）を常に狙う。
    *   **行動バイアス:** 敵DFラインの背後（アタッキング・サード/PA内）への「Run into Space」スコアが常に最大化される。
*   **ターゲットマン (Target Man):**
    *   **特徴:** 前線で身体を張り、ロングボールを収めて味方の上がりを待つポストプレイヤー。
    *   **行動バイアス:** アタッキング・サードのセンターレーンで「Hold Position (キープ)」し、味方への「Pass (落とし)」スコアが高い。
*   **フォルス・ナイン / 偽9番 (False 9):**
    *   **特徴:** 中盤サードまで下りてきてビルドアップに参加し、敵CBを釣り出して空いたスペースを味方に使わせる。CAMへのサブ適性を持ちやすい。
    *   **行動バイアス:** 保持時、ミドル・サードのセンター/ハーフスペースへの「Retreat (下りる動き)」スコアが高い。
*   **コンプリート (Complete Forward):**
    *   **特徴:** 裏抜け、ポストプレイ、足元でのキープなど、全てを高い水準でこなす万能型ストライカー。
    *   **行動バイアス:** 状況（Context）に応じて、上記3つの役割の行動を適切に選択できる。生成確率が低い（レア）。
