# 05. ミクロ（コマンド）リスト全100種 (Micro Commands List)

試合中にスロット（4枠）にセットして発動させる「ミクロ（コマンド）」の一覧。
レアリティは 6:3:1（レア1: 60種 / レア2: 30種 / レア3: 10種）、汎用30種・専用（特定戦術向け）70種の構成。
ショップ等のイベントで強化（＋化）することで、効果量の単純な上昇やCD短縮などの恩恵が得られる。

## 1. ビルドアップ（15種）
自陣からの前進・組み立てフェーズ。

**【汎用】**
- `ショートパッシング (レア1)`: ビルドアップ成功率が小アップ。
- `ロングボール配給 (レア1)`: 相手のハイプレスを回避し、最前線にダイレクト供給。
- `セーフティ・クリア (レア1)`: 自陣での危険なボールロスト率を大幅低減。
- `サイドチェンジ (レア2)`: 逆サイドへ展開し、相手スライドの隙を突く。

**【専用】**
- `サリーダ・ラボルペ (レア1)`: ボランチがCB間に落ち、3バック化してビルドアップを安定化。
- `GKビルドアップ (レア1)`: GKがパス回しに加わり、自陣で＋1人の数的優位を作る。
- `インバーテッドFB (レア1)`: SBが内側（中盤）に入り込み、中央のパスコースを増加。
- `ライン際ハグ (レア1)`: WGがタッチライン際に張り、相手DF間隔を広げる。
- `ダイレクト・フリック (レア2)`: ワンタッチでプレスをいなし、前向きの味方へ繋ぐ。
- `ターゲットマン (レア2)`: フィジカルの高いFWを狙い、セカンドボールの回収率を上げる。
- `ピンチ脱出のドリブル (レア2)`: 中盤の選手がプレスを強行突破し、局面を打開。
- `擬似カウンター (レア2)`: 自陣深くで誘い込み、一気に広大なスペースへ前進。
- `オーバーロード＆アイソレーション (レア3)`: 片側に人数を集めて相手を寄せ、逆サイドの怪物WGを1on1にする複合指示。
- `アンカーの受難 (レア3)`: アンカーが削られ役となり相手を釣り出し、2列目に巨大な縦パスコースを創出。
- `3-1-6変形 (レア3)`: ビルドアップ時に極端な前傾姿勢へ変形し、前線6人の圧倒的圧力で押し込む。

## 2. ポゼッション＆チャンスメイク（20種）
敵陣での崩し・パスワークフェーズ。

**【汎用】**
- `ワンツーパス (レア1)`: ケミストリーリンクの高い味方と壁パスで中央を突破する。
- `ミドルサード保持 (レア1)`: 中盤でボールを安全に回し、試合のテンポを落ち着かせる。
- `アーリークロス (レア1)`: DFラインが整う前に、斜めの角度からアーチをかける。
- `ミドルシュート (レア1)`: 引いた相手に対して遠目から積極的に足を振る。
- `スルーパス (レア2)`: 一撃で相手DFの間にラストパスを通す。
- `スペースラン (レア2)`: ボールのない場所へ味方が走り込み、パスコースを増やす。

**【専用】**
- `偽9番（False9）の降下 (レア1)`: CFが中盤まで落ちてマークを外し、数的優位を作る。
- `大外からのグラウンダークロス (レア1)`: ウイングがポケット（深さ）をとってマイナスに折り返す。
- `インサイドハーフのポケット侵入 (レア1)`: ペナルティエリア角のハーフスペースへ走り込む。
- `レイオフ (レア1)`: 前線の選手が落とし、前向きの選手が加速してボールを受ける。
- `アイソレーション1on1 (レア1)`: ドリブラーにボールを集め、個人の打開に賭ける。
- `3人目の動き (レア2)`: パスの出し手・受け手以外の3人目が陰から飛び出す。
- `サイドバックのオーバーラップ (レア2)`: SBが外側を爆走し、サイドの攻撃枚数を増やす。
- `インナーラップ (レア2)`: SBが内側のスペースを駆け上がり、相手を混乱させる。
- `ピンチ＆スプレッド (レア2)`: 中央を固めさせてから一気に展開する。
- `ハーフスペース集中砲火 (レア2)`: バイタルエリア周辺で細かく繋ぎ、相手ブロックを破る。
- `ハーフスペース侵入＋マイナス折り返し (レア3)`: ポケット侵入からマイナスパスを通し、確実に決定機を創出する複合指示。
- `False9＋2列目の飛び出し (レア3)`: CFの降下で開いたスペースへ、2列目が怒涛の勢いで走り込む。
- `ワンタッチ・ティキタカ (レア3)`: 全員がワンタッチでパスを繋ぎ、相手の守備意識を破壊する。
- `カオス・ポゼッション (レア3)`: ポジションを全員が無秩序に入れ替え、マーカーを完全に失惑させる。

## 3. フィニッシュワーク（15種）
ゴール手前・決定機創出フェーズ。

**【汎用】**
- `ファー詰め (レア1)`: クロスに対してファーサイドに人数をかけて飛び込む。
- `ニアハイぶち抜き (レア1)`: 角度のない場所からGKの頭上を力ずくで射抜く。
- `キャノン・ミドル (レア1)`: ブロックの外側から超強力な弾道で狙う。
- `押し込み (レア2)`: 混戦から泥臭くゴールへねじ込む。

**【専用】**
- `ライン裏抜け (レア1)`: オフサイドギリギリのタイミングでDFの背後へ抜ける。
- `カットイン・シュート (レア1)`: サイドから中央へ切れ込み、得意な足で狙う。
- `ヘディング・ターゲット (レア1)`: 高身長FWの頭にピンポイントでクロスを合わせる。
- `ループシュート (レア1)`: 飛び出してきたGKの頭上をふんわりと越す。
- `デコイラン (レア2)`: おとりの走りで相手DFを引きつけ、本命のコースを空ける。
- `ボレー・ストライク (レア2)`: 浮き球をダイレクトで叩き込む。
- `コラプシング誘発 (レア2)`: 低弾道シュートでGKの弾きを狙い、こぼれ球を狙う。
- `バイシクル / 特殊アクロバット (レア2)`: 体制が崩れた状態から強引にゴールへ飛ばす。
- `カットイン＋極上カーブシュート (レア3)`: カットインから美しいカーブを描き、逆サイドのゴール角を射抜く。
- `裏抜け＋ワンタッチ流し込み (レア3)`: 裏抜けからトラップなしで角に流し込む、一発回答の決定打。
- `全員参加の怒涛ラッシュ (レア3)`: ペナルティエリア内に6人をなだれ込ませ、決定力を極限まで高める。

## 4. プレス＆守備ブロック（20種）
非保持時のボール奪取フェーズ。

**【汎用】**
- `ミドルブロック (レア1)`: ハーフウェイライン付近に陣を張り、侵入を防ぐ。
- `パスカット (レア1)`: 相手のパスコースを予測して奪取する。
- `インターセプト＆進路限定 (レア1)`: 相手の攻撃をあえて片方のサイドへ追い込む。
- `激しいタックル (レア1)`: フィジカルでボールを奪い取る（ファウル率微増）。
- `オフサイドトラップ (レア2)`: ラインを一気に上げ、相手の裏抜けを失効させる。
- `シュートブロック (レア2)`: 体を投げ出して相手のシュートコースを遮断する。

**【専用】**
- `ハイライン・ハイプレス (レア1)`: 敵陣深くからパスコースを潰してハメ込む。
- `マンツーマン・フォース (レア1)`: 相手キーマンにぴったりとマークを張り付かせる。
- `リトリート・５バック化 (レア1)`: ウイングバックを下げてゴール前をガチガチに固める。
- `サイド限定ハメ (レア1)`: タッチラインを壁にして追い込み、ボールを奪う。
- `カバーリング (レア1)`: かわされた味方のフォローにCBが素早くカバーに入る。
- `コンパクトネス (レア2)`: 縦横の陣形を極小にし、ライン間のスペースを消し去る。
- `シャドーストライク (レア2)`: 相手のボランチをパス影に隠し、展開を封じる。
- `クロスケア (レア2)`: 中央のCBが跳ね返しに専念し、ハイボールを完封する。
- `スクリーン・ディフェンス (レア2)`: アンカーがバイタルエリアの前でフィルターになる。
- `激圧ペナルティエリア (レア2)`: ボックス内に入ってきた敵に複数人で即座に群がる。
- `ハイプレス＋一斉トラップ (レア3)`: 前線でハメつつ、逃げのロングボールもオフサイドで即殺する。
- `完全なるバス置き (レア3)`: 全員がペナルティエリアに張り付き、失点確率を極限までゼロに近づける。
- `マンツーマン・封殺ネット (レア3)`: 相手の攻撃ユニット全体を完全個別に潰し、パス回しを機能不全にする。
- `アグレッシブ・チェイシング (レア3)`: 相手のバックパスに対して全員で猛ダッシュをかけ、事故を強制誘発させる。

## 5. トランジション（15種）
攻守の切り替わり・カウンターフェーズ。

**【汎用】**
- `ファスト・ブレイク (レア1)`: 奪ったら素早く前方へボールを送る。
- `安全なバックパス (レア1)`: 奪った直後に無理をせず、GKやCBへ戻して保持を優先。
- `カウンター・プレス (レア1)`: 奪われた場所の近くの選手がすぐに寄せに行く。
- `遅延（ディレイ） (レア1)`: 相手カウンターに対し、時間を稼いで味方の戻りを待つ。

**【専用】**
- `ゲーゲンプレス (レア1)`: ボールロスト直後の5秒間、猛烈に即時奪回を狙う。
- `ロングカウンター (レア1)`: 自陣深くで奪い、最前線へ一気にロングボールを飛ばす。
- `ショートカウンター (レア2)`: 敵陣で奪った瞬間、一気になだれ込んで数的大集結を作る。
- `戦術的ファウル (レア2)`: 黄色カードのリスクと引き換えに、相手の決定的なカウンターを確実に止める。
- `プレス回避カウンター (レア2)`: 相手のハイプレスをいなした瞬間に一転して爆走する。
- `トランジション・スプロール (レア2)`: 奪った瞬間に全員が扇状に広がり、相手の守備標的を散らす。
- `セカンドボール・ハンティング (レア2)`: こぼれ球の予測位置へ真っ先に飛び込む。
- `カウンター・エクスプレス (レア3)`: 縦パス一本から最速スピードで3人が駆け上がり、一瞬でゴールを奪う。
- `ゲーゲンプレス＋ショートカウンター (レア3)`: 前線で強奪し、そのまま3秒以内にフィニッシュまで持ち込む極悪コンボ。
- `ファウル回避の超速スライド (レア3)`: ファウルを一切侵さず、洗練されたカバーリングだけで相手のカウンターを無効化する。
- `狂気の一斉スプリント (レア3)`: 奪った瞬間にチームの8人が前線へ上がり、数で殴り倒す。

## 6. シチュエーション＆マネジメント（10種）
時間帯・スコア・特殊条件付きフェーズ。

**【共通ルール（回数制限・時間条件付きなど）】**
- `【回数3】選手交代 (汎用・レア1)`: ベンチの新鮮な選手を投入し、キレを回復・戦術適応させる。
- `【回数1】パワープレー (専用・レア1)`: 終盤ビハインド時、巨漢CBを最前線に上げて放り込む。
- `【回数1】ゲームクローズ (専用・レア1)`: 終盤リード時、コーナー付近でボールをキープして時計を進める。
- `【条件：ビハインド】逆境の猛攻 (専用・レア2)`: 負けている時のみ発動。全能力が一時的に跳ね上がる。
- `【条件：前半のみ】スタートダッシュ (専用・レア2)`: 試合開始15分間、相手の動揺を誘う怒涛のアタック。
- `【条件：後半のみ】後半勝負・ガス欠狙い (専用・レア2)`: 後半30分以降、疲弊した相手をスピードで置き去りにする。
- `【回数1】トリック・セットピース (専用・レア2)`: 事前デザインされた特殊なセットプレーで奇襲をかける。
- `【条件：同点時】博打の一手 (専用・レア3)`: 同点時の終盤に発動。守備を捨てて全員攻撃に転じる。
- `【回数1】キャプテン・ゲキ (専用・レア3)`: チーム全体のコンディションとメンタルを一瞬で最高潮に持っていく。
- `【条件：ラスト5分】奇跡のラストアタック (専用・レア3)`: アディショナルタイムに発動。決定率・運補正が劇的に上昇する。
