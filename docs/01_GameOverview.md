# 01. ゲーム概要・コアサイクル (Game Overview & Core Loop)

## コンセプト
複雑なクラブ経営や面倒な試合アクション操作を一切排除し、「デッキ構築（ビルド）」と「リソース管理」に特化した、サバイバル・フットボール・ローグライト。
プレイヤーは解任の危機に瀕する「サッカー監督」となり、過密日程のなかでチームをマネジメントし、昇格・優勝の絶対ノルマに挑む。

## ターゲットプラットフォーム
- Webブラウザ（PC・スマートフォン両対応）
- 2D経営シミュレーション（カイロソフト風）の見下ろし型ビジュアルを採用。
- 技術スタック: HTML5/CSS3/JavaScript (UI管理) + Phaser 3 (試合用2D描画)

## 1ダイブ（ゲーム全体）の構造
プレイヤーは以下の3つの階層（シーズン）を戦い抜き、最終目標である1部リーグ優勝を目指す。

1. **第3部リーグ** (全9試合・10チーム制)
2. **第2部リーグ** (全9試合・10チーム制)
3. **第1部リーグ** (全9試合・10チーム制)

### サバイバル（即時解任）ルール
- 第3部・第2部リーグのクリア条件：**「昇格圏内（勝ち点ノルマ）」への到達**
- 第1部リーグのクリア条件：**「リーグ優勝」**
- **詰み（即時解任）：** シーズン途中であっても、「残り全試合に勝利しても目標勝ち点に届かない」ことが数学的に確定した瞬間、即座に解任宣告（ゲームオーバー）となり、ランが終了する。

## コア・ゲームサイクル
ゲームは主に「マネジメントフェーズ（試合間）」と「試合フェーズ」の2つを行き来して進行する。

### 1. マネジメントフェーズ (試合と試合の間)
試合が終わると、監督に「行動力（AP）」と「資金」が給付される。
提示される複数のランダムイベント（トレセン、移籍、ショップ、フロントからの要求など）に対して、これらのリソースを割り振り、次戦に向けてチームのビルドを構築・強化する。
*(詳細は `04_EventsAndResources.md` 参照)*

### 2. 試合フェーズ (オート進行 + CD制コマンド)
構築した「マクロ（宝物）」とスタメン（選手・ケミストリー）、そして4つの「ミクロ（コマンド）」を携えて試合に臨む。
試合はPhaser 3で描画される2D見下ろし型ピッチでオート進行し、セットしたコマンドがクールダウンごとに自動・または任意のタイミングで発動し、ビルドの正しさを証明する。
*(詳細は `02_MatchSystem.md` 参照)*
