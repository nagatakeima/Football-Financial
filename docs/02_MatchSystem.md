# 02. 試合システム (Match System)

## 基本仕様
試合はプレイヤーのアクション操作を必要としない**Semi-auto (オートバトル)**形式で進行する。
ビジュアルはトップダウン（見下ろし型）の2Dピッチで、デフォルメされた選手たちが自動で動き、パスやシュートを行う。
勝敗の9割は事前の「ビルド（マクロ×ミクロ×選手編成）」で決まり、残りの1割を試合中のコマンド発動が担う。
1試合の長さは現実の約5分程度を想定しており、UI上で「等倍速 / 2倍速 / SKIP (結果のみ表示)」を切り替えることが可能。

## バトル（試合）を構成する2つの柱

### A. マクロ (監督の思想・宝物/レリック)
チーム全体の戦術コンセプトや根本的な強さを決定づけるパッシブ効果。ダイブ開始時に選択する監督の初期特性や、道中のイベント・ショップで獲得する「宝物」が該当する。
MVP版では約10種類の宝物を実装予定。

- **試合外効果の例:** 初期資金が多い、スポンサー収入UPなど。
- **試合中効果の例:**
  - 「スパイクの改造」: 全選手のスピードステータス+10%
  - 「戦術ボード」: ミクロ（コマンド）のクールダウンを10%短縮
  - 「特定の戦術志向のケミストリー効果が2倍になる」

### B. ミクロ (4つのCD制戦術コマンド)
試合中にリアルタイムで発動する具体的な現場への指示。事前のマネジメントフェーズで**4つのスロット**にセットして試合に持ち込む。MVP版では約30種類を実装。

- **発動方式:** 各コマンドにはクールダウン（CD）が設定されており、CDが溜まると自動（またはプレイヤーの任意タップ）でピッチ上の選手がその戦術行動を実行する。発動時、パス成功率やシュート決定率の確率計算に強力なバフを与える。
- **シナジー効果:** 宝物（マクロ）の効果と噛み合うコマンド（ミクロ）を選ぶことで、爆発的なシナジーを生む。

## 環境・アウェーギミック
単なるステータスのぶつかり合いにならないよう、ローグライト特有の「外部要因（ランダムギミック）」が試合ごとに設定される。

- **熱狂型:** 前半の相手のプレッシャーが上昇。
- **要塞・ラフプレー型:** ファウル判定が甘く、怪我リスク・スタミナ消費が増加。
- **悪天候:** パス成功率が低下、ロングボールが有利に。
