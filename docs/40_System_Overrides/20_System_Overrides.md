# 20. System Overrides (ゲームシステムの介入)

本ドキュメントは、『サバイバル・フットボール・ローグライト（仮）』のゲームシステム（マクロ、ミクロ、スキル、環境）が、Tier 1〜3で定義された「自律的なUtility AI（ボトムアップ）」に対して、どのように外部から評価関数を「上書き（ハッキング）」するかを定義する。

---

## 1. マクロ戦術による上書き (Macro Overrides)

ダイブ開始時に選んだ監督の戦術や、道中で獲得した「宝物（レリック）」による永続的な定数バフ。
これらは全選手の評価関数の `BaseWeight` に直接乗算または加算される。

*   **ポゼッション志向:**
    *   全選手の「Short Pass」「Keep」「Support」のスコアに定数バフ（例: +20%）。
    *   CB/GKの「Clear」「Long Ball」のスコアに定数デバフ（例: -30%）。
*   **カウンター志向:**
    *   奪った瞬間（Positive Transition時）の、前線（FW/W）の「Run into Space（裏抜け）」および、ボールホルダーの「Through Pass」「Long Ball」のスコアに極端なバフ（例: +50%）。
    *   全体の「Hold Position（ビルドアップの押し上げ）」スコアを下げ、低いブロックを形成しやすくする。
*   **宝物の効果例 (スパイクの改造等):**
    *   試合中の物理パラメータ（Max Speed等）に直接係数をかける（Tier 1の物理法則への介入）。

---

## 2. 選手スキルによる上書き (Passive Skill Overrides)

特定の選手が持つ固有のプレイスタイル（パッシブスキル）による、ポジション基本ロジック（Tier 3）の例外処理。
これらは特定の条件下で、自身のスコア計算式そのものを改変する。

*   **「偽9番 (False 9)」 (CF限定):**
    *   通常のCF（前線に張る）とは異なり、ビルドアップ時に中盤（CAMやCDMの位置）まで降りてくる「Support / Hold Position」のスコアが急増する例外処理を持つ。
*   **「ラインブレイカー」 (FW/W等):**
    *   オフサイドラインと味方の「前を向いた状態」を感知するTickが他の選手より短く設定されており、裏抜け（Run into Space）の初速（ノイズ）が極めて少なくなる。
*   **「インバーテッド（偽）SB」 (SB限定):**
    *   攻撃時、大外をオーバーラップするのではなく、内側（ハーフスペース）へ絞ってCMのように振る舞うスコアが優先される。

---

## 3. ミクロ（プレイヤーコマンド）による上書き (Micro Overrides)

プレイヤーが試合中に発動する4つの戦術コマンド（CD制）。これはボトムアップAIに対する「神からの絶対的な指示（トップダウン介入）」として機能する。

*   **強制的なステート移行とスコア固定:**
    *   例：「アーリークロス」コマンド発動時、ボールを持っているサイドの選手（SB/W/SH等）の「Cross」スコアが、距離や状況（ContextModifier）を無視して強制的に `Max (9999等)` に上書きされる。
    *   同時に、前線のCF/FWに対して「PA内へのRun into Space」を強制実行させる。
*   **超強力な一時バフ:**
    *   コマンド発動によるアクション（この場合はクロスと、その直後のシュート）の成功率計算において、ノイズ（失敗確率）が極限までゼロに近づけられ、能力値以上の「理不尽なゴール/アシスト」を発生させる。

---

## 4. 環境要因とプレッシャー (Environmental Overrides)

ローグライト要素としての「試合ごとのランダムギミック」や進行状況によるデバフ。

*   **天候 (Weather):**
    *   *雨:* Tier 1で定義した「地面摩擦係数」が下がり、グラウンダーパス（Short Pass）が滑って伸びる（トラップノイズが増大する）。結果としてLong Ball/浮き球の有効性が相対的に上がる。
*   **スタジアムの熱狂 / アウェーの洗礼:**
    *   特定の時間帯（例：キックオフ直後や失点直後）に、敵チームの「Press」スコアと物理パラメータ（Acceleration）が強制的に1.2倍になる「熱狂状態」が発生する。
*   **解任のプレッシャー (Mental Debuff):**
    *   「この試合に負けたら解任（ゲームオーバー）確定」のような状況下において、Mentalの低い選手の初期Tickが長くなり（判断が遅れ）、パスミスのノイズ値が増加する。
