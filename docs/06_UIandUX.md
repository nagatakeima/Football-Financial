# 06. 画面遷移・UI/UX (UI & UX)

## 基本方針
- **マルチデバイス対応:** PCブラウザ・スマートフォンの両方で快適にプレイできるよう、レスポンシブデザインを徹底する。
- **レイアウトの原則:**
  - スマートフォン（縦持ち）: 画面を上下に分割し、上部に情報表示（メインビュー）、下部に操作系UIを配置する。
  - PC / スマートフォン（横持ち）: 画面を左右に分割し、左側に情報表示、右側に操作系UIを配置する。
- **操作性（UX）:** ボタンサイズは指でのタップを考慮し、十分なマージンを確保。重要な決定操作には2段階操作（選択→確定）を取り入れ、誤操作を防ぐ。

## 画面遷移フロー（全体図）

```text
[タイトル画面]
  │
  ├─(新規スタート)─> [監督選択画面] ──> [マネジメントフェーズ画面] (メインハブ)
  │                                    │
  └─(コンティニュー)───────────────────┤
                                       │
                                       ├─> [編成・ケミストリー確認画面] (サブ画面/タブ)
                                       ├─> [ショップ・移籍画面] (イベントからの派生)
                                       ├─> [オプション/中断セーブ画面]
                                       │
                                       └─(試合へ進む)─> [試合前確認・ミクロセット画面]
                                                            │
                                                            └─> [試合フェーズ画面]
                                                                  │
                                                                  └─> [試合リザルト画面]
                                                                        │
                                   [マネジメントフェーズ画面] <─────────┘
                                   (※解任またはシーズン終了時は [シーズンリザルト/ゲームオーバー画面] へ)
```

## 各画面の詳細設計

### 1. タイトル画面
- **機能・UI要素:** タイトルロゴ、「New Dive (新規開始)」、「Continue (再開)」、「Settings (設定)」。
- **UXの狙い:** プレイヤーが迷うことなく、すぐにゲームの世界に入れるようシンプルな構成とする。

### 2. 監督選択画面 (ゲーム開始時)
- **機能・UI要素:** 5人の監督の候補リスト。選択中の監督の詳細情報（固有フォーメーション3種、初期の宝物/マクロ、戦術志向）。
- **UXの狙い:** 監督の特徴をスワイプ（スマホ）や矢印クリック（PC）で簡単に切り替えて比較可能にする。「この監督で決定」ボタンは大きく、押しやすい位置に配置する。

### 3. マネジメントフェーズ画面 (メインハブ)
- **機能・UI要素:**
  - **ヘッダー:** 現在のシーズン・節、所持資金、残りAP（行動力）、現在の順位と目標（解任ライン）。
  - **メインエリア:** ランダムに生成された「6つのイベントカード」。
  - **フッター/ナビゲーション:** 「編成・戦術画面へ」「試合へ進む」などのタブや遷移ボタン。余ったAPを消費できる常設アクション「休養」ボタン。
- **UXの狙い:**
  - イベントカードは画面中央に配置。誤操作を防ぐため、「タップで詳細（消費APや効果）を確認」→「再度タップ（または『実行』ボタン）で確定」という**2段階の操作**を基本とする。
  - 常に現在の順位と「解任ライン」が視界に入るようにレイアウトし、ローグライト特有のサバイバル感・緊張感を演出する。

### 4. 編成・ケミストリー確認画面
- **機能・UI要素:**
  - 2Dピッチに見立てたフォーメーション配置エリア（スタメン11人）とベンチ枠（7人）。
  - 各選手のアイコン（ポジション、コンディション、戦術志向のタグアイコン）。
  - ポジション間を繋ぐ「ケミストリーのリンク線」（線の太さや色でシナジーの強さを視覚化）。
- **UXの狙い:**
  - PCではドラッグ＆ドロップ、スマホではタップ＆タップ（選択して入れ替え）の両方の操作に対応する。
  - 選手を入れ替えた際、即座にリンク線の変化（色が濃くなるなど）やステータスUPの数値をポップアップで表示し、ケミストリー構築の気持ちよさを視覚的にフィードバックする。

### 5. 試合前確認・ミクロセット画面
- **機能・UI要素:** 相手チームの情報（現在順位、特徴）と、今回の試合で発生する環境ギミック（天候、ラフプレー傾向など）の予告。4つの「ミクロスロット」と、所持しているミクロの一覧リスト。
- **UXの狙い:** ドラッグやタップ操作でミクロをスロットにセットする。相手の戦術やギミックに対してどう対策するか、思考を整理するための時間と空間を提供する。

### 6. 試合フェーズ画面 (Phaser 3 + HTML/CSS)
- **機能・UI要素:**
  - **メインビュー (Phaser 3):** 見下ろし型の2Dピッチ上で、デフォルメされた選手たちが自動で試合を進行する描画領域。
  - **HUD表示 (HTML/CSS):** 現在のスコア、試合の経過時間、倍速切替ボタン（等倍 / 2倍 / SKIP）。
  - **ミクロ操作パネル (HTML/CSS):** 事前にセットした4つのミクロボタン。各ボタンにはクールダウンの進行状況（プログレスバーや円形ゲージ）が表示される。
- **UXの狙い:**
  - Phaser 3の描画キャンバスの上に、UI要素（HTML/CSS）をオーバーレイ配置することで、レスポンシブ対応を容易にする。
  - スマホの縦持ち時では「画面上半分がピッチ（Phaser）、下半分がミクロ操作パネル（UI）」というレイアウトを想定し、試合を見ながら片手でミクロの発動指示ができるようにする。

### 7. リザルト画面 (試合・シーズン)
- **機能・UI要素:** 試合スコア、資金獲得の明細、選手の疲労蓄積・怪我の報告、そして「順位表の変動」。
- **UXの狙い:** 試合結果を受けての順位表の変動アニメーションを重視する。ノルマ（昇格圏内）を達成した際の喜びや、逆に解任ラインに近づいた際の警告（アラート演出）を強調し、次のマネジメントフェーズへのモチベーションへ繋げる。
