# 03. 選手・ケミストリーシステム (Player & Chemistry System)

## スカッド（チーム編成）の基本
プレイヤーは1ダイブにつき、最大**18人（スタメン11人 ＋ ベンチ7人）**のスカッドを管理する。
過密日程やラフプレーギミック等による疲労・怪我が発生するため、スタメンの固定は難しく、18人全員を使ったローテーション管理が求められる。

## 選手データの構成
各選手は以下のパラメータを持つ。

1. **基礎ステータス (D〜SSS):**
   - パス、シュート、ディフェンス、フィジカル、スピード、メンタル、スタミナなどの項目。
2. **プレイスタイル / 戦術スキル:**
   - 選手固有の持ち味（例: 「ラインブレイカー」「ハードプレス」「司令塔」など）。最大3〜4個を所持。
3. **国籍・所属クラブ（出身）タグ:**
   - ケミストリーシステムを発動するための属性タグ。
4. **コンディション:**
   - 試合への出場による疲労蓄積、連戦による怪我リスク、モチベーションなどを表す。

## ケミストリーシステム (リンクとシナジー)
ピッチ上のフォーメーション配置において、**隣接する特定のポジション間**に「リンク（線）」が発生する。このリンクを通じて選手同士の相性（ケミストリー）を強化することが、強力なチーム作りの鍵となる。

### リンクの基本構造 (例: 4-3-3(フラット)の場合)
- **GK:** 2人のCBとリンク
- **CB:** 同サイドのSB、同サイドのCM、中央のCDM、および相方のCBとリンク
- **SB:** 同サイドのCB、同サイドのCMとリンク
- **CDM:** 2人のCB、2人のCMとリンク
- **CM:** 同サイドのSB、同サイドのCB、CDM、同サイドのWG(またはCF)とリンク
- *※フォーメーション（4-4-2, 3-5-2など）によってリンクの張られ方は変化する。*

### ケミストリー上昇の条件
リンクで繋がった選手同士が、以下の共通点を持つ場合、リンクが「太く」なり、チームまたは個人の能力にバフ（ケミストリーボーナス）がかかる。
- **同じ国籍**であること
- **同じクラブ（またはリーグ）**の出身であること
- **相性の良いプレイスタイル**であること

### リンクと「ミクロ（コマンド）」「マクロ（宝物）」の相互作用
ケミストリー（リンク）は単なるステータスアップにとどまらず、試合中の戦術コマンド（ミクロ）の効果に直接干渉する。

1. **スキルの対象指定:**
   - 試合中に特定のミクロ（例：「ワンツーパス」や「レイオフ」）が発動した際、対象となる選手は**「リンクが繋がっており、かつケミストリーが高い選手」**が優先的に選ばれる。
   - 孤立している選手（リンクが切れている選手）は、チーム戦術から外れやすくなる。
2. **マクロ（宝物）による拡張:**
   - 「特定の国籍のリンク効果が2倍になる」「リンクが繋がっていない選手の個人能力が激増する（アイソレーション特化）」など、リンクシステム自体をハックする宝物が存在する。
