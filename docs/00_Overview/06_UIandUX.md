# 06. 画面遷移・UI/UX (UI & UX)

## 基本方針
- **マルチデバイス対応:** PCブラウザ・スマートフォンの両方で快適にプレイできるよう、レスポンシブデザインを徹底する。
- **UI/UXの優先度:** 派手なビジュアル表現よりも、モバイルとPC両方での「使いやすさ（Ease of Use）」と「タッチフレンドリーな操作性」を最優先する。
- **レイアウトの原則:**
  - スマートフォン（縦持ち）: 画面を上下に分割し、上部に情報表示（メインビュー）、下部に操作系UIを配置する。
  - PC / スマートフォン（横持ち）: 画面を左右に分割し、左側に情報表示、右側に操作系UIを配置する。
- **操作性（UX）:** ボタンサイズは指でのタップを考慮し、十分なマージンを確保。重要な決定操作には2段階操作（選択→確定）を取り入れ、誤操作を防ぐ。

## 画面遷移フロー（全体図）

```text
[タイトル画面]
  │
  ├─(新規スタート)─> [監督選択画面] ──> [マネジメントフェーズ画面] (メインハブ)
  │                                    │
  └─(コンティニュー)───────────────────┤
                                       │
                                       ├─> [編成・ケミストリー確認画面] (サブ画面/タブ)
                                       ├─> [ショップ・移籍画面] (イベントからの派生)
                                       ├─> [オプション/中断セーブ画面]
                                       │
                                       └─(試合へ進む)─> [試合前確認・ミクロセット画面]
                                                            │
                                                            └─> [試合フェーズ画面]
                                                                  │
                                                                  └─> [試合リザルト画面]
                                                                        │
                                   [マネジメントフェーズ画面] <─────────┘
                                   (※解任またはシーズン終了時は [シーズンリザルト/ゲームオーバー画面] へ)
```

## 各画面の詳細設計

### 1. タイトル画面
- **機能・UI要素:** タイトルロゴ、「New Dive (新規開始)」、「Continue (再開)」、「Settings (設定)」。
- **UXの狙い:** プレイヤーが迷うことなく、すぐにゲームの世界に入れるようシンプルな構成とする。

### 2. 監督選択画面 (ゲーム開始時)
- **機能・UI要素:** 5人の監督の候補リスト。選択中の監督の詳細情報（固有フォーメーション3種、初期の宝物/マクロ、戦術志向）。
- **UXの狙い:** 監督の特徴をスワイプ（スマホ）や矢印クリック（PC）で簡単に切り替えて比較可能にする。「この監督で決定」ボタンは大きく、押しやすい位置に配置する。

### 3. マネジメントフェーズ画面 (メインハブ)
- **機能・UI要素:**
  - **ヘッダー:** 現在のシーズン・節、所持資金、残りAP（行動力）、現在の順位と目標（解任ライン）。
  - **メインエリア:** ランダムに生成された「6つのイベントカード」。
  - **フッター/ナビゲーション:** 「編成・戦術画面へ」「試合へ進む」などのタブや遷移ボタン。余ったAPを消費できる常設アクション「休養」ボタン。
- **UXの狙い:**
  - イベントカードは画面中央に配置。誤操作を防ぐため、「タップで詳細（消費APや効果）を確認」→「再度タップ（または『実行』ボタン）で確定」という**2段階の操作**を基本とする。
  - 常に現在の順位と「解任ライン」が視界に入るようにレイアウトし、ローグライト特有のサバイバル感・緊張感を演出する。

### 4. 編成・ケミストリー確認画面
- **機能・UI要素:**
  - 2Dピッチに見立てたフォーメーション配置エリア（スタメン11人）とベンチ枠（7人）。背景には**「Pitch Matrix（5レーン×3サード）」のグリッド**が薄く描画されている。
  - 現在の監督戦術（ポゼッション、カウンター等）に応じて、**Pitch Matrix上でAIが優先的に使用するエリアがハイライト（色付け）**され、「この戦術ならどこに選手を置くべきか」を視覚的にガイドする。
  - 各選手のアイコン（メインポジションだけでなく**「役割（例: 攻撃的SB）」**を常に併記。コンディション、戦術志向のタグアイコン）。
  - ポジション間を繋ぐ「ケミストリーのリンク線」。
- **UXの狙い:**
  - PCではドラッグ＆ドロップ、スマホではタップ＆タップ（選択して入れ替え）の両方の操作に対応する。
  - **適性外配置と汎用化の警告:** 選手を適性がないポジションに配置しようとした場合、アイコンがグレーアウトし、大きな警告アイコン（⚠️）と**「汎用化（モブ化）」**のテキストが表示される。これにより、プレイヤーに「人数合わせのペナルティ」を直感的に伝える。
  - **戦術適合とリンクの視覚化:** 選手の「戦術志向タグ」が監督のチーム戦術と一致しているとアイコンが発光する。さらに、戦術志向が一致した選手間のリンク線は「太く、光る線」で表現され、ケミストリー（メッセージング感度向上）構築の正解を視覚的にフィードバックする。

### 5. 試合前確認・ミクロセット画面
- **機能・UI要素:** 相手チームの情報と、今回の試合で発生する環境ギミック（天候、ラフプレー等による物理・AIへのデバフ）の予告。4つの「ミクロスロット」と所持ミクロ一覧。
- **UXの狙い:** ドラッグやタップ操作でミクロをスロットにセット。相手の戦術やギミックに対してどう対策するか思考を整理させる。

### 6. 試合フェーズ画面 (Phaser 3 + HTML/CSS)
- **機能・UI要素:**
  - **メインビュー (Phaser 3):** 見下ろし型の2Dピッチ上で、デフォルメされた選手（頭、胴体、靴、アニメーションする脚）がボトムアップAIに従って自動で試合を進行する描画領域。
  - **HUD表示 (HTML/CSS):** 現在のスコア、試合の経過時間、倍速切替ボタン（等倍 / 2倍 / SKIP）。
  - **ミクロ操作パネル (HTML/CSS):** 事前にセットした4つのミクロボタン。クールダウンの進行状況が表示される。
- **UXの狙い:**
  - Phaser 3の描画キャンバスの上に、UI要素（HTML/CSS）をオーバーレイ配置することでレスポンシブ対応を容易にする。
  - スマホ縦持ち時では「画面上半分がピッチ（Phaser）、下半分がミクロ操作パネル（UI）」というレイアウトを想定し、試合を見ながら片手でAIを上書き（コマンド発動）指示できるようにする。

### 7. リザルト画面 (試合・シーズン)
- **機能・UI要素:** 試合スコア、資金獲得の明細、選手の疲労蓄積・怪我の報告、そして「順位表の変動」。
- **UXの狙い:** 試合結果を受けての順位表の変動アニメーションを重視する。ノルマ達成の喜びや、解任ライン接近の警告（アラート演出）を強調する。

## 2. 試合中のアクション結果UI (Match Action Popups)
試合の状況をプレイヤーが視覚的に把握しやすくするため、選手（AIエージェント）が特定のアクションや判定を行った際、頭上に一時的なポップアップテキストが表示されます。

### アクションごとの表示仕様とカラーコード
*   **パス (Pass):**
    *   成功時: `パス:成功` (青色 `#3498db`)
    *   失敗時: `パス:失敗` (赤色 `#e74c3c`)
*   **シュート (Shoot):**
    *   成功時: `シュート:成功` (青色 `#3498db`)
    *   失敗時: `シュート:失敗` (赤色 `#e74c3c`)
*   **ドリブルとタックル (Dribble & Tackle):**
    *   突破時（ドリブル成功）: FW側に `ドリブル:成功` (青色)。負けたDF側は「白く点滅（Tint）」し、数秒間のスタン（硬直）が付与される。さらに、勝ったFWはDFの進行方向と逆（背後・裏のスペース）へ瞬間的に座標移動し、「スッと抜け出した（置き去りにした）」カタルシスを演出する。
    *   奪取時（タックル成功）: DF側に `タックル:成功` (青色)。負けたFW側に `ドリブル:失敗` (赤色)を表示し、同様に白く点滅させてスタン（硬直）を付与する。
*   **トラップ / インターセプト (Trap):**
    *   成功時: `トラップ:成功` (青色 `#3498db`)
    *   失敗時（弾いた場合）: `トラップ:失敗` (赤色 `#e74c3c`)
*   **ファウル (Foul):**
    *   発生時: `ファウル` (赤色 `#e74c3c`)
*   **ゴールキーパー (GK):**
    *   セーブ成功時: `セーブ:成功` (黄色/金色 `#f1c40f`)
*   **スキル発動 (Passive Skills):**
    *   「ラインブレイカー+」「エアバトラー」などのパッシブスキルがシュート時等に発動した場合、スキル名がそのまま黄色/金色 (`#f1c40f`) で表示されます。

### 挙動の制約 (Cooldown)
UIが重なりすぎて視認性が低下するのを防ぐため、また物理的に不自然な連続タッチを防ぐため、アクション（パスやトラップ失敗など）を起こした直後の選手には短い「アクションクールダウン（約1秒）」が付与され、ボールに再干渉できなくなります。またボール自体にも蹴られた直後に「無敵時間」が存在します。
