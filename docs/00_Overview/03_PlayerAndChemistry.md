# 03. 選手・ケミストリーシステム (Player & Chemistry System)

## スカッド（チーム編成）の基本
プレイヤーは1ダイブにつき、最大**18人（スタメン11人 ＋ ベンチ7人）**のスカッドを管理する。
過密日程やラフプレーギミック等による疲労・怪我が発生するため、スタメンの固定は難しく、ローテーション管理が求められる。

## 選手データの構成と生成フロー
本作における選手は「どのポジションができるか」だけでなく、「そのポジションでどう振る舞うか（役割）」が不可分なセットとして生成される。

### 1. ポジションと役割（ロール）のセット
選手は獲得（生成）時、**「ポジション ＋ 役割（ロール）」**をセットとして1〜4つ（メイン1つ、サブ最大3つ）獲得する。
*   *例:* 「攻撃的SB（メイン） / ウイングバック（サブ）」
*   **生成フロー（ローグライト要素）:**
    1.  まず「メインのポジションと役割」が抽選される。
    2.  その役割を遂行するのにふさわしい基礎ステータスやスキルが優先的に付与される。
    3.  その後、必須級以外のオマケのステータスやスキルもランダムに抽選される。
    4.  付与された全ステータスの傾向から、論理的に適合する「類似のポジション・役割（サブ適性）」があればそれを追加獲得する。
*   これにより、単なるポジションの互換性ではなく、「その選手のプレイスタイル（役割の性質）」に沿ったサブ適性が生まれる。

### 2. 配置の制約と汎用（モブ）化ペナルティ
*   選手は原則として、適性（メインまたはサブ）を持つポジションに配置する。
*   **適性外への配置:** UI上、無理やり適性外のポジションへ配置することは可能（緊急時の人数合わせ等）。しかしその場合、選手は**「汎用（モブ）化」**する。
    *   本来持っていた「役割」によるAI行動バイアスや固有スキルが一切機能しなくなる。
    *   基礎ステータス（後述のBaseWeight計算）に極めて重いデバフ（例：全ステータス半減等）がかかる。
    *   監督の戦術指針も上手く読み取れず、ノイズだらけの非効率な動きを繰り返す。

### 3. 基礎ステータスとエンジンへの影響
- **総合値（OVR）:** 8つのポジション（GK, CB, SB, CDM, CM, CAM, WG, CF）ごとの主要ステータスの重み付け計算によって個別に算出される（例：GKはDEF/MEN中心）。
*   内部的には 1〜100 の数値。
   - **スピード・フィジカル:** 最高速度、加速度、減速度（アジリティ）、ジャンプ、衝突（ノックバック）など物理演算の直接的なパラメータとなる。
   - **メンタル (Mental):** Utility AIの「思考Tick（判断速度）」を短縮し、視野（首振りの頻度）と「脳内マップの空間記憶時間」を拡張する極めて重要なステータス。
   - **スタミナ:** ダッシュやジャンプ、ターンで消費し、歩行やデッドボールで回復する。低下すると身体能力が落ちるだけでなく、「IQ Drop（ノイズ増加、視野狭窄）」を引き起こし、判断ミスやライン統制の崩壊に繋がる。
   - **パス・シュート・ディフェンス:** ファーストタッチ（トラップ）の乱数や、特定アクション成功時のノイズ低減に寄与する。
3. **選手スキル (Passive Skill Overrides):**
   - 試合中の確率計算への永続ボーナスや、選手のAI挙動を書き換える（Overridesする）能力。最大4個所持。
   - スキルは「無印」と「＋」が存在し、＋で強力な二次効果が付与される。特定のポジション配置時のみ発動する制限を持つ。
   - 例: 「偽9番」や「ラインブレイカー」は、AIの基本ステートマシンの優先度を改変する（Tier 4 参照）。
4. **戦術志向タグ:**
   - 監督のチーム戦術（ポゼッション、カウンター等）に対する好みを表す属性。
5. **コンディション:**
   - 疲労蓄積、怪我リスク。

## ケミストリーシステム (戦術リンクとコーチング連動)
ピッチ上のフォーメーション配置において、**隣接する特定のポジション間**に「リンク（線）」が発生する。

### チーム戦術への適合とケミストリーの強化
- **リンクの条件:** フォーメーション上で隣接する選手同士が同じ「戦術志向」を持つ場合、リンクが太くなる。
- **チーム戦術へのコミット:** 監督のチーム戦術（Tactical Directives）と自身の戦術志向が一致している選手は、戦術の指針（スコアバイアス）をより強く受け入れる。不一致の場合はノイズが混じり、チームの指針から浮いたプレイ（ポゼッション戦術なのにロングボールを蹴る等）をしやすくなる。
- **ボトムアップAIへの影響:** ケミストリーリンクが成立している味方同士は、Tier 1で定義された「コーチング（メッセージ）」の伝達速度（感度）が劇的に上がる。これにより、味方のメッセージ（例: 「裏へ走るぞ」「カバーを頼む」）を受信した際の `MessageBonus` 倍率が高まり、「あうんの呼吸」による素早いパス交換や連動したプレッシングが実現される。

### リンクと「ミクロ（コマンド）」の相互作用
- 試合中に特定のミクロ（強制指示）が発動した際、対象となる選手は**「リンクが繋がっており、かつケミストリーが高い味方（＝メッセージ受信感度が高い味方）」**が優先的に選ばれ連携する。
