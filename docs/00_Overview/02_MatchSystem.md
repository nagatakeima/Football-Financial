# 02. 試合システム (Match System)

## 基本仕様
試合はプレイヤーのアクション操作を必要としない**Semi-auto (オートバトル)**形式で進行する。
ビジュアルはトップダウン（見下ろし型）の2Dピッチで、デフォルメされた選手たちが自動で動くが、内部のシミュレーションエンジンは極めて高度な「Z軸（高さ）」や「物理法則（バウンド・回転・摩擦）」を持つ3次元空間として計算される。
全体を統制する上位AIは存在せず、全選手（AIエージェント）が毎思考Tickごとに Utility AI を用いて自己判断し、メッセージングで連携する**ボトムアップ型のアーキテクチャ**を採用する（詳細は `docs/10_MatchEngine_Core/` を参照）。

勝敗の9割は事前の「ビルド（マクロ×ミクロ×選手編成）」で決まり、残りの1割を試合中のコマンド発動が担う。
1試合の長さは現実の約5分程度を想定しており、UI上で「1x / 2x / 4x / 一時停止 / 結果までスキップ (結果のみ表示)」を切り替えることが可能。

## バトル（試合）を構成する2つの柱

### A. マクロ (監督の思想・宝物/レリック)
チーム全体の戦術コンセプトや根本的な強さを決定づけるパッシブ効果。ダイブ開始時に選択する監督の初期特性や、道中のイベント・ショップで獲得する「宝物」が該当する。
これらは、ボトムアップAIの評価関数における「BaseWeight」を書き換える定数バフとして機能する（例：ポゼッション志向ならショートパスのスコア増）。

- **試合外効果の例:** 初期資金が多い、スポンサー収入UPなど。
- **試合中効果の例:**
  - 「スパイクの改造」: 全選手のスピードステータス+10%
  - 「戦術ボード」: ミクロ（コマンド）のクールダウンを10%短縮
  - 「特定の戦術志向のケミストリー効果が2倍になる」

### B. ミクロ (4つのCD制戦術コマンド)
試合中にリアルタイムで発動する具体的な現場への指示。事前のマネジメントフェーズで**4つのスロット**にセットして試合に持ち込む。
- **神の介入 (System Overrides):** コマンド発動時、自律的なUtility AIの思考は一時的に「ハッキング」され、強制的なステート移行や、ノイズ（失敗確率）が極限までゼロに近づく理不尽なバフが付与される。

## 試合ギミック (Environmental Overrides)
ローグライト特有の「外部要因（ランダムギミック）」がAIの物理計算や評価関数に直接介入する。
- **fever (熱狂):** 前半の相手のプレッシャー（物理パラメータ）が上昇。
- **badWeather (悪天候):** 地面摩擦係数が下がりボールが滑るためトラップミス（ノイズ）が増加。ロングボールのスコアが相対的に有利になる。
- **fortress (要塞):** 順位や状況の重圧により、Mentalステータスの低い選手の思考Tickが遅れ、判断ミスが増加する。
